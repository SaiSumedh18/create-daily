# Create Daily

A creative coding study: an origami koi folded entirely in code, swimming over a red page.

- **Folded in code** — the koi is generated from diamond cross-section rings, a forked tail, a pleated dorsal fin and paper pectorals. No models or textures; colour is assigned per face.
- **Swims like a fish** — a travelling sine wave runs head to tail, growing toward the fin; tail-beat frequency scales with speed and the body banks into turns.
- **Follows you** — move the pointer to lead it, click or tap to drop food. Left alone it wanders a lissajous path.

Built with Three.js, TypeScript, Vite and Archivo. Add `?poster` to the URL to hold a composed still pose.

```bash
npm install
npm run dev
```
